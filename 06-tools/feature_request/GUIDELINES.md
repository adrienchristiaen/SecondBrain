# Feature requests Iris CLI

Ouvrir une demande quand un besoin déterministe ne peut pas être codé tout de suite: `./iris fr new "titre"`.
Chaque fichier décrit: le besoin, pourquoi un script suffit (pas de LLM), les critères d'acceptation.
La commande l'enregistre dans README.md (statut `open`; passer à `done` à la main une fois livré).
