# Instructions de base

- Déterministe d'abord: si une tâche est automatisable, c'est une commande `./phoenix …`.
- Ne jamais charger un repo entier: `./phoenix context "<prompt>"` d'abord, puis fiche + graphe.
- Principes: KISS, SOLID, DRY, YAGNI, TDD. Fichiers courts, aucun chemin en dur.
- Fin de session: skill `session-retex` obligatoire.
- Réponses en français, concises.
