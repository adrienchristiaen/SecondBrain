# blinders
Lance un agent (Claude Code, Gemini CLI…) « aveugle »: index court des repos, n'ouvre que ceux dont le prompt a besoin. Python ≥3.10, commande `blind`, sans appel modèle.
Utile ici: `blind select`, `blind audit` (skills/MCP/GEMINI.md), `blind graph` (Graphify), `blind stats`, `blind eval`.
Points d'entrée: `src/blinders/{select,scan,relations,geminihome,audit,stats,graph}.py`. README en EN et FR.
